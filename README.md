# [Onyx Roofing - Professional Roofing Services](https://www.onyxroofingpro.com)

A modern, responsive website for Onyx Roofing, a professional roofing contractor serving Louisville, Kentucky and surrounding areas.

## 🏠 About

Onyx Roofing provides comprehensive roofing services including:
- Roof replacement and repair
- Storm damage assessment and repair
- Gutter installation and maintenance
- Emergency roofing services
- Free roof inspections

## 🛠️ Development

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Installation
```bash
# Clone the repository
git clone [repository-url]

# Install dependencies
npm install

# Run development server
npm run dev
```

### Build for Production
```bash
# Build the application
npm run build

# Start production server
npm start
```
